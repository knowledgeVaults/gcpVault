# Google Cloud: Workforce Identity Federation

**WIF** is an IAM solution that provides users with access to Google Cloud services and resources using an already existing identity management solution within an organization

* Eliminates the maintenance and security burden associated with service account keys by allowing organizations to use federated identities instead

<br>

# Workforce Identity Pools

Workforce Identity Pools are logical containers that group external workforce identites for federated access to GCP resources

* Enables organizations to apply IAM policies directly to the pool instead of individual accounts
* Created at the organization level and remain available across all projects and folders within it
